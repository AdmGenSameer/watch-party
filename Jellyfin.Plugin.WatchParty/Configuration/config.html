Netflix-style Cinema UI & Sub-100ms Synchronized Watch Parties

🚀 Client Navigation Integration:
✓ Native Navigation Drawer (Active): A "Watch Party" menu entry with a group icon is automatically registered in the Jellyfin sidebar (Library section) for Jellyfin Web and Jellyfin Media Player Desktop!
Direct URL: /tokoshan/
💡 Optional: Direct Sidebar Button via Custom JavaScript

If you prefer a direct link that navigates the full window directly to /tokoshan/ instead of the embedded cinema frame, paste this into Dashboard > General > Custom JavaScript code: 

(function() {
  function addWatchPartyButton() {
    const navDrawer = document.querySelector('.mainDrawer-scrollContainer');
    if (navDrawer && !document.querySelector('#nav-watchparty')) {
      const link = document.createElement('a');
      link.id = 'nav-watchparty';
      link.className = 'navMenuOption emby-button';
      link.href = '/tokoshan/';
      link.innerHTML = `
        groups
        Watch Party
      `;
      navDrawer.appendChild(link);
    }
  }
  setInterval(addWatchPartyButton, 1000);
})();
